# 🎉 幸运大抽奖 v3（单机版 · 完整管理后台）

一台电脑 + Python 就能跑的抽奖系统：**按活动管理**、**可视化后台**、**手机扫码签到**、**Excel 批量导入**、**大屏抽奖**。
无需部署外部服务器、无需单独安装数据库或第三方包（仅用 Python 标准库）。

---

## 🚀 启动

```bash
cd lottery-web
python3 server.py            # 默认 8000，可改端口：python3 server.py 8080
```

| 用途 | 地址 | 是否需登录 |
| --- | --- | --- |
| 🔐 **登录页（首页）** | `http://<电脑IP>:8000/` | 无需（进入系统的入口，可登录 / 注册 / 找回密码） |
| 🎛 **管理后台** | `http://<电脑IP>:8000/admin` | **必须登录**（未登录自动跳回登录页） |
| 📺 **抽奖大屏** | `http://<电脑IP>:8000/screen` | 免登录（现场投影） |
| 📱 **签到二维码** | `http://<电脑IP>:8000/qr` | 免登录 |
| ✍️ **手机签到** | `http://<电脑IP>:8000/checkin` | 免登录（现场来宾扫码填姓名加入名单） |

要求 Python 3.8+（Windows / macOS / Linux 均可），数据自动保存在 `lottery.db`（SQLite）；旧版 `data.json` 会在首次启动时自动迁移并备份。

## 🎛 管理后台能做什么

### 🔐 账号与角色（普通用户 / 管理员）
**本系统必须登录才能使用**：首页 `/` 就是登录页，登录后进入管理后台；未登录访问 `/admin` 会被自动跳回登录页。
**扫码签到、大屏、二维码页仍对所有人免登录开放**（现场来宾不用注册，扫码即可参与）。

| 角色 | 能做什么 |
| --- | --- |
| **管理员** | 管理**全部**活动 + 用户管理（新建、改角色、禁用、重置密码、删除）+ 系统设置与备份恢复 |
| **普通用户** | 创建活动，并管理**自己创建**的活动；看不到也改不了别人的活动 |

- 首次使用打开 `/` 会直接进入「创建第一个管理员」（注册时设置安全问题）；此后其他人自行注册即为普通用户
- **找回密码**：登录页「找回密码」→ 输入用户名 → 回答注册时设置的安全问题 → 自行重设密码（无需管理员介入）
- 密码使用随机盐 + SHA-256 存储，会话用 HMAC 签名 cookie（7 天有效），登录态失效会跳回登录页
- 系统始终保留**至少一个可用管理员**：降级/禁用/删除最后一个管理员会被拒绝
- 活动带「创建者」，删除用户不会删除其活动；普通用户的活动仅自己与管理员可见
- 越权访问（改别人活动、拉别人名单、导出别人名单）一律返回 `403`

> 旧版本的「管理口令」已下线。若旧数据里存在口令，首次启动会自动迁移为 `admin` 账号（密码不变）。

### 📊 仪表盘
活动总数 / 进行中 / 名单人次 / 中奖人次 四张统计卡；当前活动的奖项进度条；最近加入名单与最近中奖动态。

### 🎪 活动管理
- **新建 / 编辑 / 复制 / 删除**活动，活动带状态：`未开始 · 进行中 · 已结束`
- 一键「设为当前」，大屏与二维码自动跟随
- 搜索、按状态筛选、卡片式展示奖项进度

### 📋 活动详情（5 个页签）
| 页签 | 内容 |
| --- | --- |
| **概览** | 名单来源构成（扫码/导入/手动）、奖项进度、签到地址与二维码入口 |
| **名单** | 搜索（姓名/部门/手机/工号）、按来源与中奖状态筛选（**可直选"🏆 一等奖"这类具体奖项**）、分页、批量选择删除、单条编辑/删除、导出 CSV、清空；已中奖者在「中奖奖项」列显示 🏆 奖项名，一人多次中奖会全部列出 |
| **抽奖** | 点选奖项 → 开始抽奖 → 结果卡片 + 中奖者墙，可「撤销最近一次」或跳下一奖项 |
| **中奖记录** | 按奖项分组表格、移除单条、手动补录、撤销最近一次、导出 CSV |
| **设置** | 活动名称/备注、奖项配置（名额 + 每次抽取人数）、抽奖规则、签到设置、**活动时段**、手动状态 |

### 🕒 活动时段（自动开始 / 自动结束）
新建或编辑活动时可以设置起止时间，到点自动切换状态、自动开关签到通道，现场不用手动切：

| 时间 | 状态 | 签到 | 大屏 |
| --- | --- | --- | --- |
| 现在 < 开始时间 | 未开始 | ❌ 提示「签到还没开始（xx 开放）」 | 顶部显示 ⏳ 未开始 |
| 开始时间 ≤ 现在 < 结束时间 | 进行中 | ✅ 正常签到 | 正常 |
| 现在 ≥ 结束时间 | 已结束 | ❌ 提示「本活动已结束，签到通道已关闭」 | 顶部显示 🔒 已结束 |

- 开始/结束时间都可留空：只填结束时间＝立即可签到、到点自动关；只填开始时间＝到点开放、不自动关
- 服务端有后台线程每 5 秒检查一次，**到点自动落库并通过 SSE 推送**，大屏和后台无需刷新
- 时间以运行服务的这台电脑为准；关闭「按时间自动开始/结束」后，状态回到手动选择
- 快捷按钮：`从现在开始`、`2 小时后结束`、`今晚 18:00–22:00`、`清空`

### ✍️ 签到字段完全自定义
「活动 → 设置 → 签到填写项」里可以**自由增删字段、改字段名、设是否必填**：

- 「姓名」是固定字段（必填，不可删除）
- 内置可选：工号、部门、手机号
- **自定义字段**：点「＋ 添加自定义字段」，填字段名即可（如 `桌号`、`公司`、`岗位`、`渠道`）

自定义字段会同时出现在：手机签到表单 → 后台名单表格（独立列）→ 导入向导的列映射 → 导出 CSV。
签到校验也会生效：设为「必填」的字段没填，手机端会提示。

### 📥 导入向导（模板 + 预览 + 列映射 + 结果报告）
**先下载模板**（导入弹窗第一步有按钮，名单页也有）：模板会**按当前活动配置的字段自动生成表头**（姓名 + 部门/工号/手机号 + 你自定义的字段），Excel 版表头加粗并冻结首行。填表规则：

| 规则 | 说明 |
| --- | --- |
| 第一行表头 | 不要修改或删除，否则列会认错 |
| 姓名列 | 恒为**必填**，空着的整行自动跳过（结果里计入"无效行"） |
| 其它列 | **能否留空由管理员在「设置 → 签到填写项」里的必填开关决定**：设为必填的列模板表头带 `*`，每行都必须填；没标 `*` 的列随便留空 |

必填规则是跟着活动走的：把「部门」设成必填后，新下载的模板表头就是 `部门*`，导入时缺部门的整行会被跳过并在结果里提示「有 N 行缺少必填项被跳过：李四（缺部门）」；改成非必填后同一份表就能全部导入。

流程：
1. 上传填好的 `.xlsx / .csv / .txt`，或直接粘贴名单
2. 预览前 12 行 → 自动识别表头并**预填列映射**（可手动改）→ 实时提示"有 N 行未填必填项「部门」，将跳过"、"必填字段「部门」还没选列"→ 选「追加 / 覆盖」「是否跳过重复」
3. 结果报告：新增 / 重复跳过 / 无效行 / 名单总数 + 缺必填项的具体名单

必填同样约束其它入口：手动添加人员时会拦截并提示"请填写「部门」"；编辑已有人员时把必填字段清空也会被拒绝。

兼容性：xlsx 用标准库直接解析；CSV 支持 UTF-8 / GBK；表头为空的单元格不会导致列错位。

## 📺 抽奖大屏（只有三块内容）

- 左：**抽奖名单**（已中奖者灰显）
- 中：**滚动名字 → 停顿 → 揭晓中奖者**（彩带 + 音效），上方是当前奖项与剩余名额
- 右：**中奖名单（按奖项分组展示，组间有分隔）**，可在活动设置里切换成紧凑名单模式

快捷键：`空格或回车` 抽奖，`← →` 切换奖项，`⛶` 全屏，`🔔` 静音。
一个奖项抽完会自动出现「▶ 下一奖项」按钮。

## 📲 关于「必须同一个 Wi-Fi」

扫码签到的本质是手机能访问到电脑上的服务，所以**手机和电脑必须在同一网络**。现场做不到时，在活动「设置 → 签到方式」里三选一：

| 方式 | 适用场景 |
| --- | --- |
| **局域网扫码**（默认） | 手机与电脑同一 Wi-Fi，最简单 |
| **开热点自建网络** | Windows 移动热点 / 手机热点，电脑和大家连同一个热点，不依赖场地 Wi-Fi |
| **公网地址扫码** | 用 `cloudflared tunnel --url http://localhost:8000` 或 ngrok 拿到公网地址填进设置，手机用流量也能扫 |
| **仅手动导入** | 完全不用手机，名单全部 Excel 导入 |

## ❓ 常见问题

**手机打不开签到页？** 确认同 Wi-Fi；macOS 在系统设置 → 网络 → 防火墙放行 Python；Windows 首次弹窗选「专用网络」；或改用热点 / 公网地址方案。

**Excel 导入没读到人？** 确保第一列是姓名（或表头含"姓名"）；导入向导里可手动指定哪一列是姓名。

**"没有可抽奖的人员"？** 名单为空，或已中奖的人被规则过滤（默认不允许重复中奖）。

**忘记密码？** 在登录页点「找回密码」→ 输入用户名 → 回答注册时设置的安全问题 → 自行重设密码，无需管理员介入。若账号未设置安全问题，请联系管理员在「用户管理」里重置。

**管理员账号被禁用 / 全被删了？** 系统会拒绝删除/禁用最后一个可用管理员；若极端情况下 `users` 被清空，重新打开 `/` 即可创建新的第一个管理员（活动数据保留在 `data.json` 中）。

**普通用户看不到某个活动？** 活动按创建者隔离，只有创建者本人与管理员可见。

**端口被占用？** `python3 server.py 8080`，二维码与地址会自动更新。
