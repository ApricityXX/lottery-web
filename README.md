# 幸运大抽奖

![版本](https://img.shields.io/badge/version-v1.0-2ea44f)

一个适合年会、班会、门店和团建活动的抽奖系统。只需一台电脑和 Python，即可管理活动与名单、手机扫码签到，并在大屏上实时抽奖。无需单独安装数据库，也不依赖第三方 Python 包。

![抽奖大屏](docs/screenshot.png)

## 功能

- **活动管理**：独立配置奖项、名额、每次抽取人数、活动时段和抽奖规则
- **名单管理**：扫码签到、Excel/CSV/TXT 导入、自定义签到字段、搜索筛选与 CSV 导出
- **实时大屏**：滚动抽奖、中奖展示、彩带音效，名单和结果实时同步
- **账号权限**：管理员与普通用户分权，支持注册、找回密码和活动数据隔离
- **多种签到方式**：局域网、一键远程、自定义公网地址或仅手动导入
- **数据管理**：SQLite 本地存储，支持 JSON 备份与恢复

## 快速开始

要求 Python 3.8+，支持 Windows、macOS 和 Linux。

```bash
git clone https://github.com/ApricityXX/lottery-web.git
cd lottery-web
python3 server.py
```

默认监听 `8000` 端口，也可以指定其他端口：

```bash
python3 server.py 8080
```

启动后访问以下页面。将 `<主机>` 替换为运行服务的电脑或服务器 IP；在本机访问时可使用 `localhost`。

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 登录 / 注册 | `http://<主机>:8000/` | 首次使用创建管理员账号 |
| 管理后台 | `http://<主机>:8000/admin` | 需要登录 |
| 抽奖大屏 | `http://<主机>:8000/screen` | 现场投影，免登录 |
| 签到二维码 | `http://<主机>:8000/qr` | 展示当前活动的签到入口 |
| 手机签到 | `http://<主机>:8000/checkin` | 来宾填写信息加入名单 |

大屏快捷键：`空格 / 回车` 抽奖，`← / →` 切换奖项，`⛶` 全屏，`🔔` 静音。在终端按 `Ctrl + C` 停止服务。

> 仓库为私有仓库，克隆前需要已有的访问权限；如果拿到的是压缩包，解压后进入目录执行 `python3 server.py` 即可。

## 手机扫码签到

在活动的「设置 → 签到方式」中选择适合现场的方式：

| 方式 | 适用场景 | 配置说明 |
| --- | --- | --- |
| 局域网 | 手机与电脑连接同一 Wi-Fi | 直接使用；若无法访问，检查电脑防火墙是否允许 Python 接收入站连接 |
| 一键远程 | 手机使用移动网络或不同 Wi-Fi | 需安装 ngrok，并在终端自行执行 `ngrok config add-authtoken` 完成授权 |
| 自定义公网地址 | 已有域名、公网服务器或反向代理 | 填写完整入口，例如 `https://lottery.example.com`；建议使用 HTTPS |
| 仅手动导入 | 不开放扫码 | 完全通过 Excel/CSV/TXT 导入名单 |

新建活动默认使用「一键远程」。使用 ngrok 时，在「活动 → 概览」点击「启动远程签到」，连接成功后打开二维码页；重新连接后如果地址变化，需要重新展示二维码。ngrok 授权令牌不要提交到项目或发送给他人。

如果服务直接部署在公网服务器，也可以选择「自定义公网地址」并填写服务器入口，例如 `http://服务器IP:8000`。直接暴露端口时没有 HTTPS 加密，正式使用更建议通过 Nginx 和域名代理，并只开放 `80/443`。

## 名单导入与导出

导入弹窗可下载按当前活动字段生成的 Excel 模板，支持表头识别、列映射、数据预览、重复跳过和结果报告。各字段是否必填由活动设置决定，姓名也可以选填，但每个活动至少要有一个必填字段。名单和中奖记录均可导出 CSV。

## 数据与隐私

- 运行数据保存在服务目录下的 `lottery.db`；旧版 `data.json` 会在首次启动时自动迁移
- 远程签到通过 ngrok、自定义公网入口或反向代理转发，名单和中奖记录保存在运行服务的机器上
- 大屏、二维码和公开签到接口只返回展示所需字段
- 管理后台支持数据备份与恢复；备份文件包含账号和活动数据，请妥善保管
- `lottery.db`、备份文件、授权令牌和环境配置不应提交到公开仓库

## 常见问题

**端口被占用**：运行 `python3 server.py 8080` 更换端口。

**没有可抽奖人员**：检查名单是否为空，以及默认的“不允许重复中奖”规则是否已过滤全部中奖者。

**忘记密码**：在登录页通过注册时设置的安全问题重设；未设置安全问题时，请联系管理员重置。

**手机打不开签到页**：确认二维码中的地址能从手机访问，并检查签到方式、防火墙、安全组和反向代理配置。
