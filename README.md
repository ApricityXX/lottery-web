# 幸运大抽奖

一个适合年会、班会、门店和团建活动的本地抽奖系统。只需一台电脑和 Python，即可管理活动与名单、手机扫码签到，并在大屏上实时抽奖。无需单独安装数据库或第三方 Python 包。

## 核心功能

- **活动管理**：独立配置奖项、名额、抽取人数、活动时段和抽奖规则
- **名单管理**：扫码签到、Excel/CSV/TXT 导入、自定义签到字段、搜索筛选与 CSV 导出
- **实时大屏**：滚动抽奖、中奖者展示、彩带音效，名单与结果实时更新
- **账号权限**：管理员与普通用户分权，支持注册、找回密码和活动数据隔离
- **远程签到**：内置 ngrok 一键连接，手机无需与电脑处于同一网络
- **数据管理**：SQLite 本地存储，支持 JSON 备份与恢复

## 快速开始

要求 Python 3.8+，支持 Windows、macOS 和 Linux。

```bash
python3 server.py
```

默认监听 `8000` 端口，也可指定其他端口：

```bash
python3 server.py 8080
```

启动后访问以下页面（将 `<电脑IP>` 替换为实际地址）：

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 登录 / 注册 | `http://<电脑IP>:8000/` | 首次使用创建管理员账号 |
| 管理后台 | `http://<电脑IP>:8000/admin` | 需要登录 |
| 抽奖大屏 | `http://<电脑IP>:8000/screen` | 现场投影，免登录 |
| 签到二维码 | `http://<电脑IP>:8000/qr` | 展示当前活动签到入口 |
| 手机签到 | `http://<电脑IP>:8000/checkin` | 来宾填写信息加入名单 |

大屏快捷键：`空格 / 回车` 抽奖，`← / →` 切换奖项，`⛶` 全屏，`🔔` 静音。

## 手机扫码签到

### 局域网签到

手机与电脑连接同一 Wi-Fi 即可，无需公网或额外工具。若无法访问，请检查电脑防火墙是否允许 Python 接收入站连接。

### 一键远程签到

新建活动默认使用此方式，适合手机使用移动网络或不同 Wi-Fi 的场景：

1. 安装 ngrok，并首次在终端自行运行 `ngrok config add-authtoken` 完成授权。授权令牌不要提交到项目或发送给他人。
2. 在「活动 → 设置 → 签到方式」中选择「一键远程签到」，可填写已在 ngrok 配置的固定域名，也可留空自动分配。
3. 在「活动 → 概览」点击「启动远程签到」，连接成功后打开二维码页供来宾扫码。
4. 活动结束后停止远程签到；若重新连接后地址变化，请重新打印二维码。

也支持填写已有的公网入口，或完全关闭扫码、仅通过 Excel 导入名单。

## 名单导入与导出

导入弹窗可下载按当前活动字段自动生成的 Excel 模板，支持表头识别、列映射、数据预览、重复跳过和结果报告。各字段是否必填由活动设置决定（姓名也可选填），但每个活动至少要有一个必填字段。名单和中奖记录均可导出 CSV。

## 数据与隐私

- 运行数据保存在本机 `lottery.db`，旧版 `data.json` 会在首次启动时自动迁移
- 远程签到仅通过 ngrok 转发访问，名单与中奖记录仍保存在本机
- 大屏、二维码和公开签到接口仅返回展示所需字段
- 管理后台提供数据备份与恢复；备份文件包含账号和活动数据，请妥善保管
- `lottery.db`、备份文件和环境配置不应提交到公开仓库

## 项目结构

```text
lottery-web/
├── server.py              # HTTP 服务、权限与业务逻辑
├── db.py                  # SQLite 存储与数据迁移
├── parsers.py             # 名单解析与 Excel 模板生成
├── tunnel.py              # ngrok 远程签到管理
├── static/                # 管理后台、大屏、签到与二维码页面
├── lottery.db             # 运行数据（自动生成）
└── README.md
```

## 常见问题

**端口被占用**：运行 `python3 server.py 8080` 更换端口。

**没有可抽奖人员**：检查名单是否为空，以及默认的“不允许重复中奖”规则是否已过滤全部中奖者。

**忘记密码**：在登录页通过注册时设置的安全问题重设；未设置安全问题时，请联系管理员重置。
